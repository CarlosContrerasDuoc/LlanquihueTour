# Llanquihue Tour

## Descripción
Este proyecto representa informacion de clientes y empleados de una agencia de turismo mediante un programa creado por Java.

## Clases principales
- Persona: Guarda los datos generales de una persona.
- Direccion: Guarda la ciudad y la calle.
- Cliente: Guarda los datos del cliente y su reserva.
- Empleado: Guarda los datos del empleado, su cargo y sueldo.
- LlanquihueTour: Es la clase Main la cual imprime y muestra la informacion por consola.

## Cómo ejecutar
Abre el proyecto en NatBeans y ejecuta la clase LlanquihueTour.
